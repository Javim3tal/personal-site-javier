# Whole-project review (PLAN task 4)

Date: 2026-10-24. Baseline: HEAD `53ef736` (content, design and prototype layers built in parallel). This review covers the three layers running together on localhost. It fixes the integration defects and checks the result against SPEC "Quality bar" and "Definition of done". Nothing is committed yet.

## Summary

The three layers met their contracts on paper, but they clashed once combined. The biggest clashes were in the CSS: `base.css` drew borders, padding and gaps inside components that `theme.css` also styled. That broke the experience timeline, boxed the hero stats, doubled the spacing inside cards and doubled the certification hairlines. The renderer and the theme both printed the "Coming soon" label. The hero used the tagline as the `h1` instead of the name. The review also found that the **downloadable CV PDF contained the phone number**.

All of these are fixed in the working tree. One blocker is still open, and it is about git history rather than the files on disk (see "Remaining open items").

## What was verified, and how

Served with `python3 -m http.server 8080` (root) and with a parent folder on `:8081` to test sub-path hosting (`/javier-ortiz-website/`). Driven with Playwright (Chromium). Final checks ran in fresh browser contexts, so no cached CSS was involved. Both servers were stopped afterwards.

- **Every section renders from `content.js`** at 360, 375, 768, 1280 and 1440 px × light, explicit dark (localStorage) and system dark: 15 combinations. All 7 sections had content. There was 0 horizontal overflow (no element extends past the viewport, even ignoring `body { overflow-x: hidden }`), exactly one `h1`, exactly 3 "Coming soon" labels, and **0 console errors or warnings and 0 HTTP ≥ 400**. 700 and 1000 px were also checked.
- **Sub-path:** `http://127.0.0.1:8081/javier-ortiz-website/` at 375 and 1440 px. All sections render, fonts and tokens load, and the CV resolves to `/javier-ortiz-website/assets/…` with 200 `application/pdf`. No errors.
- **Mobile menu** (375 px): the toggle opens the panel, sets `aria-expanded="true"` and changes its label to "Close menu". Escape closes the menu and returns focus to the toggle. Choosing a link closes the menu and navigates. A click outside closes it.
- **Theme toggle:** light → dark sets `data-theme`, `localStorage.theme`, `aria-pressed="true"` and `theme-color`, and persists across reload. An explicit light choice wins over system dark. With no stored choice, the site follows the system theme live.
- **Active nav link:** About, Experience, Certifications and Contact each get `.is-active` and `aria-current="location"`. Anchors land exactly under the sticky header (section top = 64 px = `--header-h`).
- **Reveal:** below-the-fold blocks start hidden and become visible on scroll. Under `prefers-reduced-motion: reduce`, all 29 are visible immediately (opacity 1, no transform), smooth scroll is off and the status-dot pulse is off. In print, all are visible.
- **Keyboard:** the first Tab shows the skip link, and Enter focuses `#main`. The tab order runs hero CTAs → contact buttons → email link → header. Every stop has a 2 px `--color-focus` outline (screenshots below).
- **Contrast:** every visible text run (181) was checked against its composited background in light, system dark and explicit dark, with **0 failures**. Lowest values: 5.30:1 (light, section eyebrow on the alternate band) and 6.33:1 (dark, status pill). The DESIGN.md table covers UI boundaries (≥ 3:1).
- **Links:** both "Download CV" links use the relative path with `download` and return 200 `application/pdf`. Email uses `mailto:`. LinkedIn has `target="_blank" rel="noopener"` and an sr-only "(opens in a new tab)". No in-page anchor is broken.
- **Meta / SEO:** title, description, OG and Twitter tags match `content.js`. JSON-LD parses as a valid `Person`.
- **No JS:** with JS disabled in light and dark, the noscript fallback shows the name `h1`, tagline, location, CV, email and LinkedIn. The system dark theme applies through CSS. The nav stays inline and there is no overflow.
- **Renderer robustness** (fixture injected by route interception, no file added to the repo): live, wip and placeholder cards with a relative image load full-bleed at 16:9 with links in a new tab. With empty `projects` the page shows 3 placeholders. Empty `stats`, `certifications`, `availability` or `headline` hide their blocks and the matching nav link, and the section numbers renumber.
- **Phone number:** grep across the whole repo (excluding `docs/cv.txt`) for digit runs, `tel:`, `+34`, "phone" and "móvil" found nothing. The text extracted from the CV PDF has no phone after the fix.
- **Static checks:** `node --check assets/js/main.js` passed. The CLAUDE.md `node -e` check loads all 11 content keys. CSS braces balance. `base.css` contains no raw colours. All 74 tokens are referenced.
- **Not run:** Lighthouse (not available here). Performance was judged by inspection: two small scripts at the end of `<body>` plus a tiny inline theme script, three stylesheets and one font `@import` (see #28).

Screenshots are outside the repo, in `$TMPDIR/jo-review/` (`before-*` = baseline, `final-*` = after the fixes).
